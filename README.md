One funny out-of-office reply, one line long: the away message hands the
job to its own auto-reply, and the auto-reply is already asking for a raise.
It reads like a real message someone would switch on before going away, and
the joke lands on the first read.

## Run it

```sh
python3 main.py
```

Writes exactly one line (91 characters) to `/output/entry.txt`.
Deterministic: the same line on every run. Python 3 standard library only,
no network, no randomness.
